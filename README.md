# Daikibo Telemetry Analysis with Tableau

## 📌 Project Overview
This project analyzes telemetry data from four Daikibo manufacturing facilities to identify the biggest causes of production line disruptions using Tableau.

## 🧠 Business Problem
The client, Macora Industries, wanted to know:
- Which factory had the most machine breakdowns?
- Which machine type caused the most issues in that factory?

## 📊 Tools Used
- Tableau (for data analysis and visualization)
- JSON (data source format)

## 📈 Key Insights
- **Daikibo Factory Seiko** in Osaka had the highest machine downtime.
- The **LaserWelder** machine caused the most issues in that factory.

## ✅ Conclusion
The dashboard created in Tableau helped identify Seiko factory and LaserWelder machines as the main causes of production line disruptions. These insights can help Macora target maintenance and reduce downtime.
